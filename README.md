# NEBULA: The Last Signal

A 2D space-survival shooter in a single HTML file (HTML + CSS + vanilla JS, no dependencies, works offline).

**Run:** open `index.html` in any modern browser (Chrome, Edge, Firefox, Safari). No server or internet needed.

**Controls:** WASD/Arrows move · Mouse aim · Click/Space fire · Shift dash · R reload · Q/E/Right-click nova bomb · Esc/P pause · M mute.
On touch screens: left thumb moves, right thumb aims and fires, and on-screen buttons trigger dash, nova and reload.
